# 4. 修复 Audit BLOCKER — Runtime

当前公开 README 声称：

```text
numpy 2.0.2
scipy 1.13.1
```

等 Runtime 可用，

但正式 Sandbox 内：

```text
import numpy
import scipy
import sympy
import torch
```

均不可用。

不得通过扩大 Sandbox 权限来迁就旧文档。

本轮首先从**正式 Sandbox 内部**探测真实 Runtime。

生成：

```text
competitor-kit/RUNTIME_MANIFEST.md
```

只列正式 Sandbox 实际可用内容。

例如如果实测只有 Standard Library，则明确：

```text
Python: 3.9.6

Third-party packages:
NONE
```

不要列宿主能够 import、但正式 Solver 无法 import 的库。

同时修正所有公开资料中的旧 Runtime 表格。

# 7. 修复 Variable Schema

当前 Audit 发现：

文档使用：

```json
{
  "type": "variable",
  "name": "x"
}
```

但 parser 实际读取：

```text
value
```

并且非法/missing value 会被静默当作 x。

本轮必须消除静默歧义。

建议冻结正式格式为：

```json
{
  "type": "variable",
  "value": "x"
}
```

Validator 必须：

```text
value missing
→ INVALID

value != "x"
→ INVALID
```

例如：

```json
{
  "type": "variable",
  "name": "y"
}
```

不得静默解释成 x。

新增永久回归。

# 13. 修复 CRASH 根因截断

当前错误：

```text
stderr.slice(0,1000)
```

可能保留前部而切掉真正：

```text
ModuleNotFoundError
```

本轮允许对此做最小实现修复。

要求：

- stderr 仍有严格大小上限；
- 不允许 output flooding；
- 但必须尽量保留最终 exception / traceback tail；
- 常见 Python import/runtime error 必须让参赛者看到根因。

例如可采用 bounded head + tail：

```text
[first N bytes]

... truncated ...

[last N bytes]
```

或其他可靠方案。

新增 regression：

```text
missing-module
runtime exception
syntax error
```

均必须保留可识别根因。

```text

> 若算法需要临时文件，应优先使用当前工作目录或 `tempfile` / `TMPDIR`。

with tempfile.NamedTemporaryFile(...) as f:

```

不得硬编码：

```text
/tmp
/work
/Users/...
```

# 18. Recommendation vs Requirement

重写 `ALGORITHM_REQUIREMENTS.md` 时明确分成：

## MUST

不满足会导致：

```text
Preflight failure
Invalid Shot
Timeout
Competition violation
```

## SHOULD

强烈建议但不影响接口合法性。

## MAY

可选开发策略。

例如：

```text
atomic result write
```

必须根据真实 Runner 判断到底属于 MUST 还是 SHOULD。

不得把推荐写成协议硬要求。
