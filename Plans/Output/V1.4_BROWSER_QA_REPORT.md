## 3. 可访问性检查 / Accessibility

- 全部操作都是真实 `<button>` / `<a>`，`focus-visible` 全局描边；主动作禁用时**可见**原因 + `aria-describedby`；候选锚点按钮 `aria-pressed`；回放播放 / 速度按钮 `aria-pressed`，时间轴 `aria-valuetext`；帧列表 `aria-current`。
- 错误按来源分层（`ErrorNotice` `data-scope=participant|package|preflight|round|judge|connection|server`），错误 / 警告 `role=alert`，成功 / 信息 `role=status`。
- 不靠颜色单独表达：LOCKED 有文字与 `data-locked`；步骤条 done / now / todo 各有字形（✓ / ▸ / 序号）与 `data-state`；胜者 / 终局原因是文字徽章；连接状态是文字 + `data-status`。
- `prefers-reduced-motion: reduce` 下停掉连接与计算的呼吸动画；竞技场揭示动画原本就尊重该设置。
- 键盘：裁判主动作 ⌘/Ctrl+Enter（危险动作不绑；按钮始终可见）；回放播放器聚焦时 ← → Space Home End。

## 4. 跨平台 / Cross-platform compatibility status

| 平台 | 状态 |
|---|---|
| macOS · Google Chrome | **PASS**（本报告全部实测都在这里） |
| macOS · Safari | **未测试** |
| Windows · Chrome / Edge | **未测试** |

静态兼容检查（`web/src` 全文 grep）：快捷键修饰键按 `navigator.userAgentData.platform` → `navigator.platform` 判定 Meta（Mac）/ Ctrl（其它），按钮始终可见，快捷键不是唯一路径；
ZIP 解压用平台 `DecompressionStream('deflate-raw')`（Chrome 80+ / Edge / Safari 16.4+），失败时报错而不静默；目录上传用 `webkitdirectory`（Chrome / Edge / Safari 均支持）；
`localStorage` 只存语言且包在 try/catch 里（私密模式不崩）；画布 DPR 钳位到 2、不参与命中判定；WebSocket 为标准 API。**没有发现 macOS 专属假设**；关键流程不依赖快捷键。

## 6. 已知 P2 / P3 与限制

- 1280 宽的英文裁判台 / 回放页，顶栏元信息会换到第二行（无溢出，仅多 ~20 px 高）。
- ≤1100 px 视口按设计隐藏导航链接（品牌名仍链回首页）—— 1024×768 因此零溢出，但导航要靠首页。
- 访问不存在的回放时 Chrome 自己会在控制台记一条 `Failed to load resource: 404`（浏览器网络日志，非页面错误；没有 e2e 走这条路）。
- 回放列表 / 侧栏的队名来自产物里的 `teamAName`，目前服务端写的是「Team A / Team B」；前端在与队别标签重复时去重显示。
- `TeamBoard.lastError` / `CommandResult.errors` 等服务端自由文本仍是中文（英文界面下标题句已翻译、正文原样透传）。
- Advanced 里「按路径安装」的两步确认没有 e2e 覆盖（类型检查与 reset 确认同一实现）。
- ⌘+Enter 只在 macOS 实测；Ctrl+Enter 分支未实测。
- 未截图 COUNTDOWN / COMPUTING 这两个亚秒级阶段的大屏（布局与其它阶段相同，文案来自 `PHASE_KEYS`）。
