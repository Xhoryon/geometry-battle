## 6. 最高优先级证据

详细问题 G0-01～G0-11 在平台基线 §5。当前暂定 **1 个 P0 条目、6 个 P1 条目**，其余按 P2/后续验证分类；这不是完整独立 RC 漏洞总数。

1. **G0-01 跨队读取**：只用本轮新建合成 B 标记，A 安装 Preflight 通过必须先成功读取它；返回 `ok=true`。已知路径由测试宿主捕获，未证明路径发现能力，未接触真实包或秘密。
2. **G0-03 deadline**：sleep 650 ms / 预算 500 ms 正常 TIMEOUT；本探针宿主暂停 1000 ms 后 Runner success、1005.4385 ms。正式 Match 无独立时间拒绝是静态链结论；没有把它说成完整正式比赛攻击复现。
3. **G0-05 几何**：`y=x+sqrt(2)-1e-6` 穿过单位圆，Validator 合法、Judge 无阻挡并击杀后方点；较深穿圆对照正确阻挡。尚未测生成地图中的发生率。
4. **G0-04 runtime**：真实 sandbox 普通 worker thread 成功；合成同 Python/Linux runtime 判 OK。没有测多核性能优势或真实 Linux 比赛。
5. **G0-08 prepare**：UPLOAD_A 下 action enabled，调用返回拒绝重新上传 A。
6. **G0-06/G0-07**：普通交互 judge 到 READY；Web prepare 到 EMITTER_SELECT，匿名观众投影此时含障碍物。观众读取不等于算法 GO 前执行。
