## Known Issues

### V1.3/V1.4 Public Distribution

**One test failure in clean checkouts**: `tests/operator-e2e.ts` — "judge: 只给 --auto 就能开一场正规比赛"

**Root cause**: Test depends on runtime state (`runs/slots/.slots/<team>.json`) which is `.gitignore`d. Clean checkouts lack this state, causing the `READY` status assertion to fail.

**Impact**: Platform behavior is unaffected. The test failure is cosmetic (console display of "READY" text) and does not affect match execution.

**Documentation**: Documented in `docs/RELEASE_NOTES.md` with full explanation.
