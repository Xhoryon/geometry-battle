## 3. Local Validator 与官方 Preflight 的关系（§12）

「本地自检的规则 == 官方 Preflight 的规则」**不是承诺，而是结构性的**：
自检工具不实现任何判定，它调用的是平台生产代码本身。

| | 本地自检 | 官方 Preflight |
|---|---|---|
| 判定代码 | 同一份 | 同一份 |
| 沙箱 | 真实沙箱（`sandbox-exec` + `scrubEnv`） | 真实沙箱 |
| 世界 | 固定 decoy 种子 `20250111` | `matchId` 派生的 decoy 世界 |
| 队别 | A、B 各跑一次 | 按槽位跑一次 |
| 结论 | `PRE-FLIGHT PASS` / `FAIL` | `Preflight: PASS` / `FAIL` |

两者都**不泄漏**比赛信息：decoy 世界与比赛种子无关。
